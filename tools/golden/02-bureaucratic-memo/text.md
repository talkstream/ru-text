В целях повышения эффективности взаимодействия между подразделениями было принято
решение о проведении мероприятий по оптимизации документооборота.

Ответственными лицами осуществляется контроль за надлежащим исполнением поручений.
В соответствии с утверждённым регламентом информация подлежит рассмотрению в
установленные сроки.

По итогам проведённой работы будет подготовлен отчёт, который направляется руководству
для принятия соответствующего решения.
