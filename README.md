**Плагин для Claude Code, Codex, Notion, Cursor, GitHub Copilot и [ещё семь платформ](#быстрый-старт) — качество русского текста** — типографика, информационный стиль, редактура, UX-тексты и деловая переписка.

Более 2 000 лингвистических атомов (правил, пар «плохо → хорошо», словарных статей и исключений), основанных на изучении 16 канонических русскоязычных источников. Все формулировки оригинальные — без дословного цитирования, с полной атрибуцией.

## Что делает плагин

ru-text даёт вашему ИИ-ассистенту глубокое понимание качества русского текста. Плагин активируется автоматически при создании или редактировании текста на русском: типографика применяется мгновенно, доменные справочники подгружаются по мере необходимости.

Работает с Claude Code (CLI и Desktop), Codex CLI, Notion, Cursor, GitHub Copilot, Gemini CLI, Google Antigravity, Windsurf, Continue.dev, Cline, JetBrains (Junie) и OpenClaw.

- **более 2 000 атомов** в девяти справочниках и файле источников
- **Автоактивация** — не нужно помнить о включении
- **Полное покрытие** — от длинного тире и кавычек-ёлочек до UX-микрокопирайтинга и тона деловой переписки
- **Не догма** — ваш явный запрос стиля всегда приоритетнее правил по умолчанию

## Сценарии использования

**Этот README.** Каждое тире, кавычка и пробел в этом документе соответствуют правилам самого плагина. Текст написан с подключённым ru-text.

**UX-микрокопирайтинг.** Пишете кнопки, ошибки, пустые состояния для русскоязычного приложения. Плагин подгружает справочник UX-текстов: «Отмена» вместо «Нет», структура ошибок (что случилось + что делать), плейсхолдеры как примеры, а не инструкции.

**Деловое письмо.** Набрасываете email коллегам или клиентам. Плагин убивает канцелярит («довожу до сведения» → «сообщаю»), структурирует тему + первое предложение + призыв к действию, подсказывает уважительный тон без заискивания.

**Текст для лендинга.** Пишете блок «О компании» для IT-студии. Плагин заменяет штампы («команда профессионалов», «индивидуальный подход») на конкретные факты и цифры.

**README и документация.** Пишете документацию для open-source проекта на русском. Правильная типографика (ёлочки, тире, неразрывные пробелы), ясная структура «перевёрнутой пирамиды».

**Вычистка нейрослопа.** Текст похож на сгенерированный. Плагин ловит 16 примет машинного текста. Пять видны прямо во фрагменте:

- ложная антитеза («не X, а Y» без посылки);
- непрошенная самопохвала («чётко, по делу, без воды»);
- сервисные реплики ассистента («Отличный вопрос!», «Надеюсь, помог»);
- пустые зачины («давайте разберёмся», «погрузимся»);
- неопределённая атрибуция («как показывают исследования» без исследования).

Ещё девять ловятся так же: объявленная искренность, обязательная триада, выхолощенность, аддитивная псевдопара, избыточные тире, парцелляция, разжёвывание очевидного, возражение без предпосылок и рассогласование подлежащего со сказуемым.

Две приметы плагин предъявляет не фрагменту, а документу целиком, потому что правкой на месте они не лечатся: текст, который остался стенограммой диалога с нейросетью, и текст, написанный для поисковика, а не для читателя.

У каждой приметы есть оговорка, где приём законен: цитата, разбор чужого текста, юридическая формула, перечисление, где четвёртому элементу взяться неоткуда. Плагин читает оговорку раньше, чем выносит замечание.

**Оценка качества текста.** Хотите знать, насколько хорош ваш текст? `/ru-text:ru-score` оценивает текст по пяти измерениям (типографика, чистота языка, грамотность, структура, точность для читателя) и возвращает балл от 0 до 10 с конкретными замечаниями по каждому измерению. Балл печатается как посчитался, но у верхних ярлыков есть пол: документ, который оказался стенограммой диалога или написан для поисковика, не назовут «Эталонным» или «Хорошим» ни при какой арифметике — и рубрика скажет, каким правилом ярлык ограничен.

**Качество ИИ-агентов.** Встраиваете ИИ-инструменты в продукт и не уверены, как именно ответит агент на русском? ru-text гарантирует предсказуемо высокое качество текста от любого Claude-агента: единообразная типографика, никакого канцелярита, структура от читателя.

## Быстрый старт

Дайте эту фразу своему ИИ-агенту:

> Установи навык https://github.com/talkstream/ru-text глобально и вызывай его для любых задач с русским текстом: вычитка, типографика, редактура, UX-тексты, деловая переписка.

Дальше он справится сам: где его площадка держит навыки, агент знает лучше, чем инструкция,
написанная год назад. Проверено на Claude Code, Codex CLI, Cursor, GitHub Copilot, Gemini CLI,
Google Antigravity, Windsurf, Continue.dev, Cline, JetBrains Junie и OpenClaw. Notion ставится
кликом, а не агентом — путь в [INSTALL.md](INSTALL.md).

Ставите руками, агент промахнулся или площадка ставит навык своим установщиком —
[INSTALL.md](INSTALL.md): каталоги всех площадок с адресами вендорской документации,
клик-пути Claude Desktop и Notion, четыре факта, которые перебором не открыть,
и обновление.

Начните писать на русском в новой сессии: навыки подхватываются при её старте, а не в той сессии, где вы их поставили. Если ru-text делает ваши продукты лучше,
поддержите [разработку](https://github.com/sponsors/talkstream).

| Информационный стиль | [`info-style.md`](skills/ru-text/references/info-style.md) | Стоп-слова (92 записи), структура текста, факты вместо оценок, регистр, редполитика Т–Ж |

| Редактура: грамматика | [`editorial-grammar.md`](skills/ru-text/references/editorial-grammar.md) | Заглавные буквы, согласование, плеоназмы, управление, деепричастие с чужим субъектом, контекстные омофоны, оформление списков |
| UX-тексты | [`ux-writing.md`](skills/ru-text/references/ux-writing.md) | Надписи на кнопках, ошибки, пустые состояния, формы, уведомления, диалоги, онбординг |
